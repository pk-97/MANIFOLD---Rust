# RT Instancing Design — ray-traced Scene Loop / Scene Mirror copies

**Status:** APPROVED — design complete 2026-09-05, P0–P3 briefed · k3 (lead)
**Lifecycle: contract** — the RT instancing path (`RtObjectGeometry` instance binding, the TLAS descriptor-build kernel, per-slot material rows) cites this doc's D-numbers and invariants as its spec.

Peter, 2026-09-05: *"if RT does not work with instances it will look horrible and janky."* Scene Loop and Scene Mirror (both landed 2026-09-05) render copies through `Array<InstanceTransform>` buffers consumed by the raster path only; the RT accel structure instances each object once at its base `model` transform, so loop copies and mirrored copies are invisible to RT shadows, AO, GI, and reflections. This wave removes that limitation — the deferred trigger of SCENE_MIRROR_DESIGN.md D7 (rt-inherits-instancing-limitation), pulled forward.

## 2. Decisions

- **D1 — GPU-side TLAS descriptor build; the CPU never reads instance values.** Instance buffers are GPU-resident (freeze-path compute atoms write them); composing `model·T_instance` on the CPU would need a per-frame readback — a sync stall on the content thread, rejected outright. Rejected also: CPU recompute of producer atoms (fusion boundary makes the wired buffer's provenance opaque to render_scene; generic `Array<InstanceTransform>` producers exist — scatter_on_mesh). A small MSL compute kernel — the **descriptor build kernel** — runs one thread per (object, slot): reads the slot's `InstanceTransform` by bindless address, composes `world = model_obj · T_inst` (D4 math), writes one `MTLAccelerationStructureInstanceDescriptor` (mask 0 for dead slots, D2) into a GPU-private descriptor buffer the TLAS build/refit consumes. The existing CPU `build_instance_buffer` path stays for the no-instances fast path (D7).
- **D2 — TLAS slots = Σ per-object instance capacities; dead slots are mask-0 descriptors, never compaction.** Metal needs the instance count at TLAS build time (CPU-side); live-ness is in-band (zero scale, GPU-side). Rejected GPU compaction (count would become GPU-side; indirect TLAS descriptors are new Metal surface for zero win at ≤128 descriptors). A dead slot gets identity matrix + `mask = 0` — every query masks nonzero, so it is provably never intersected. Capacity change = slot count change = topology (D9). Memory ceiling: Σ capacities × 64 B descriptors (8 objects × 16 slots = 8 KB) — negligible; no fixed cap, sized per build like today.
- **D3 — instance_id expands to per-slot; per-slot material rows; the kernel's normal chain replicates `vs_main`'s fold.** Slots are ordered object-major: object i owns slots `[base_i, base_i + cap_i)`; `instance_id` indexes slots. `RtNormalSource` and `GiMaterial` rows are emitted PER SLOT (object's row duplicated across its slots) by the same per-frame `ensure_*` cadence — kernels keep indexing by `instance_id`, unchanged. `RtNormalSource` gains (consuming the two `_pad2` words, size stays 120 B): `instance_addr: u64` (bindless address of THIS slot's `InstanceTransform`, 0 = unwired) and `object_index: u32` (D6). Normal fetch: when `instance_addr != 0`, load `rot_pad`, apply `n' = rot·(n·msign)` to the interpolated LOCAL normal, THEN the row's `normal_matrix` (object model) — bit-parity with `render_scene.wgsl:781-813`, including `euler_xyz`. Rejected: per-hit `object_to_world` inverse-transpose (hot-path cost on every fetch, rewrites every existing proof's ground truth for zero behavioral gain on rigid instances).
- **D11 — row layout split: canonical per-object rows at `[0, N)`, slot rows at `[N, N+Σ)` (P0 review amendment, supersedes D3's object-major duplication for the material tables).** P0 review found that object-indexed consumers — `n4.w` readers in `accumulate_irradiance`/`atrous_filter` (roughness), the RS-C emissive sampler (`normal_sources[object_index]`) — break under variable per-object capacities: no duplicated-row layout puts object i's row at index i when capacities vary. Layout: one buffer, `[0, N)` canonical per-object rows (object-indexed sites UNCHANGED), `[N, N+Σ)` per-slot rows addressed by `instance_id` — instance-indexed sites gain a params-carried `slot_row_base = N` offset. `RtNormalSource.object_index` still names the owning object for `n4.w`; slot rows carry it too. Rejected: a per-slot→object indirection buffer (an extra dependent load on every hit for a mapping the split layout makes free) and pure duplication with a base map (same extra load, worse).
- **D12 — the tangent frame folds with the instance too (P0 review amendment).** `perturb_normal_with_map` derives T/B from LOCAL mesh edges × the object model matrix; under instancing the instance `rot·msign` is absent from the frame (vertex normals are exact via D3). Fix: apply the same D3 fold to the edge vectors before the model matrix (edges are directions, exactly like the normal). Scope-limited to the primary-hit normal-map path; secondary rays keep vertex normals as today.
- **D4 — Descriptor composition math = the raster's, exactly.** 3x3 `A = euler_xyz(rot)·diag(msign·scale)`, translation `t = pos`; world 4x3 = `model_obj · (A | t)`. `msign` from the marker exactly as `render_scene.wgsl:781-786` (`select` per component, marker = `u32(w+0.5)`). Mirrored slots therefore carry a negative-determinant instance matrix — Metal accepts arbitrary affine 4x3 in instance descriptors; intersection is correct because the kernels never cull by winding (anchor). Normals stay correct via D3 (inverse-transpose of a reflection is the reflection; the msign fold IS the inverse-transpose for this transform family).
- **D5 — No new Metal instance options in v1.** The trace kernels issue `reset(ray, accel, mask)` with no cull mode — two-sided default, matching the raster's cull-free contract; mirrored (winding-flipped) triangles intersect identically. ⚠ VERIFY-AT-IMPL: the P2 mirror proof (ray at the mirrored copy's expected location, assert hit + normal) is the arbiter; if Metal's default culls by winding on any tier, the mirrored slot's descriptor gets the flipped `triangleFrontFacingWinding` option — decide on proof evidence, not documentation.
- **D6 — `n4.w` carries object_index, not instance_id.** `RtNormalSource.object_index` (D3) is what the primary hit packs into `n4.w`; `obj_motion` stays per-object. Per-INSTANCE motion is not tracked — the same documented v1 gap as the raster velocity path (`render_scene.wgsl:798-801`: a moving instance array contributes no per-instance velocity). Uninstanced scenes: `object_index == instance_id`, byte-identical.
- **D7 — No-instances fast path is byte-identical to today.** When NO opaque draw has `instances` wired: CPU descriptor build, one descriptor per object, per-object rows (`instance_addr = 0`), existing refit — the photoscanned-hero-object scenes this path was tuned for see zero change (INV-RTI3). When ANY object is instanced, the GPU path serves ALL objects uniformly (unwired objects contribute one identity slot, `instance_addr = 0`) — one code path when active, no per-object mode mix.
- **D8 — Emissive light table expands per slot; world composition moves into the kernel.** Table entries become (local-space triangle, object_index, slot_index); the alias table is built CPU-side from LOCAL power (area×luma) duplicated per slot. The alias is only a proposal distribution: the kernel recomputes each sampled entry's TRUE world area (cross product of the composed world-space edges) for the RIS weight, so the estimator is unbiased under any per-slot scales. The kernel reads the composed world matrix from the TLAS descriptor buffer, bound ALSO as a storage buffer (it is our buffer — no second source of truth). Dead-slot entries: world scale 0 → area 0 → zero contribution, with a guard against 0/0 in the pdf (skip, contributes nothing). Entry cap `MAX_RT_EMISSIVE_TRIANGLES` now spans slots: rank by local power per (object, slot), same cap.
- **D9 — Keys: capacity rides topo, generation rides accel(refit), values ride the GPU.** Topo key gains per-object `instance_slots` capacity (capacity change = TLAS slot-count change = rebuild; buffer identity does NOT ride — the descriptor kernel reads whatever buffer is wired each frame, and per-slot rows are rewritten per frame). Accel (refit) key gains each wired slot's `instances_generation`: static loop/mirror buffers never bump it — zero per-frame RT cost beyond today (INV-RTI4); a re-scattering producer bumps it every frame and gets a per-frame refit, which is correct. Refit in instanced mode = descriptor-build dispatch + TLAS refit in ONE command buffer (GPU-ordered; the CPU-mapped-buffer tear discipline of `render_scene.rs:5762-5772` does not apply — the buffer is GPU-private, written and read on the same queue). Content key untouched. BUG-rmmv (topo-shrink-trace-overrun)'s topo-key trace gate already covers slot-count shrink (rows are rebuilt per frame from the same objects slice).
- **D10 — Proofs are value-level against CPU-computed expectations, synthetic buffers only.** No real import fixtures (BUG-twa6 (real-import-device-seed-nondeterminism) — device-seed nondeterminism must not gate). Oracle: for each slot the CPU computes the expected world transform from the same TRS/mirror math and casts one ray per assertion.

## 3. Invariants

- **INV-RTI1 (RT sees the raster's instance set):** every live raster slot has exactly one TLAS instance at the same world transform; every dead slot has none (mask 0). *Enforcement:* gpu proof — loop count=4, one probe ray per expected copy position, assert hit object + distance vs CPU expectation; a fifth ray at a dead slot's would-be position asserts miss.
- **INV-RTI2 (mirror exact in RT):** a mirrored slot's RT geometry is the exact planar reflection of its source (INV-MR2 carried into accel space); the interpolated normal at the hit equals the mirrored normal. *Enforcement:* gpu proof vs CPU-computed reflection, position AND normal.
- **INV-RTI3 (no-instances parity):** a scene with no wired `instances` takes the D7 fast path — existing rt gpu proofs (rt_p1_shadow, rt_t1b, rt_t2a, rt_emissive_*, rt_tl_*, rt_r3, rt_t2c) run UNCHANGED and green.
- **INV-RTI4 (static instances are free):** static instance buffers (loop/mirror) trigger no descriptor dispatch and no refit beyond today's transform-driven cadence. *Enforcement:* code path keyed on `instances_generation` (D9); `MANIFOLD_PROBE_RT_ACCEL` logs one line per descriptor dispatch so a stray per-frame rebuild is visible in logs; rt_noise_gate ceilings unchanged.
- **INV-RTI5 (capacity is topology):** `instance_slots` capacity change rebuilds the accel through the BUG-308 (rt-accel-async-build-defer) one-frame defer; content/value changes refit. *Enforcement:* key audit in P1 review; proof that a count=1→4 scene_array param change does NOT rebuild (capacity is buffer-fixed, BUG-757c (scene-loop-copies-param-inert)) but rewires do.
- **INV-RTI6 (no CPU readback):** no `.mapped_ptr()`/readback of any `instances` buffer anywhere on the RT path. *Enforcement:* review; the values only ever move GPU→GPU.

## 4. Phases

### P0 — manifold-gpu: descriptor build kernel + per-slot expansion
- **Scope:** `crates/manifold-gpu/src/metal/raytrace.rs` only. `RtObjectGeometry` gains `instances_addr: u64` (0 = unwired) + `instance_slots: u32` (0/1 = unwired). New MSL descriptor-build kernel (embedded MSL, same file's discipline): per-(object, slot) thread; MSL mirror of `MTLAccelerationStructureInstanceDescriptor` sized by `size_of` const-assert (do NOT assume 64 — assert and stride); MSL mirror of `InstanceTransform` (32 B, matches mesh_common.rs:96); `euler_xyz` bit-parity copy with a comment naming the two raster sources. `build_accel`: when any object has `instance_slots > 1`, allocate GPU-private descriptor buffer of Σ slots, dispatch the kernel ahead of the TLAS build on the same encoder, per-slot `accelerationStructureIndex = object index`; else today's CPU path. `refit_accel`: instanced mode re-dispatches the kernel + refits in one command buffer; CPU rewrite path unchanged otherwise. `ensure_normal_sources` / gi-materials upload expand to per-slot rows (object-major order) with `instance_addr` + `object_index`; `RtNormalSource` consumes `_pad2` (size stays 120, MSL mirror updated in lockstep). Kernel normal fetch gains the D3 fold behind `instance_addr != 0`. `n4.w` packs `object_index` (D6).
- **Forbidden:** new `Arc<Mutex>`; CPU readback of instance buffers; changing any existing kernel behavior when `instance_addr == 0`; `create_compute_pipeline(include_str!(…))` outside this file's established embedded-MSL pattern.
- **Gates:** `cargo clippy -p manifold-gpu -- -D warnings`; `cargo nextest run -p manifold-gpu`; `scripts/gpu_proofs_gate.py` green (existing proofs = INV-RTI3's first half).

### P0.5 — manifold-gpu: D11 row-layout split + D12 tangent fold (P0 review rework)
- **Scope:** `raytrace.rs` only. Split the `RtNormalSource`/`GiMaterial` tables per D11: canonical per-object rows at `[0, N)`, slot rows at `[N, N+Σ)`, params gains `slot_row_base`; every instance_id-indexed read site adds the base, object-indexed sites unchanged. D12: `perturb_normal_with_map`'s edge directions take the D3 fold before the model matrix. Harden `refit_accel`'s instanced branch with a slot-sum assert (build vs refit Σ slots equality — the count assert alone can't see capacity shrink).
- **Gates:** same as P0.

### P1 — render_scene wiring + keys
- **Scope:** `render_scene.rs`. Populate `instances_addr`/`instance_slots` from `d.instances`/`d.instance_count` (buffer GPU address — the same bindless-address mechanism `vertex_base_addr` uses; verify GpuBuffer exposes it at :5492's construction site). Topo key += per-object slots; accel key += `d.instances_generation` (D9). Remove the KNOWN LIMITATION comment (:5482-5489) — replaced by a pointer to this doc. GiMaterials build stays per-object (expansion inside manifold-gpu, D3).
- **Gates:** clippy + nextest `-p manifold-renderer`; `scripts/gpu_proofs_gate.py`.

### P2 — proofs + noise gate
- **Scope:** `crates/manifold-renderer/tests/gpu_proofs/rt_instancing.rs` (new, registered like its siblings): (a) INV-RTI1 loop proof; (b) INV-RTI2 mirror proof (position + normal); (c) dead-slot miss; (d) capacity-vs-count (count=3 of capacity 8: exactly 3 copies traced); (e) INV-RTI4 probe assertion (no dispatch logged across 3 static frames). All synthetic — build tiny vertex/instance buffers in-test, CPU computes expectations. Run `scripts/gpu_proofs_gate.py` and `scripts/rt_noise_gate.py` (record NOTHING unless drift is real; drift with zero golden change = BUG-cam (gpu-proofs-firmware-fault-class) environment class — document, don't re-baseline).
- **Gates:** both scripts green.

### P3 — emissive table per-slot (D8)
- **Scope:** `EmissiveTriangleCpu` gains `slot_index`; table build duplicates candidates per slot (local-power rank, cap spans slots); kernel composes world positions from the bound descriptor buffer and recomputes true world area for the RIS weight; dead-slot zero-area guard. `refit_emissive_table`'s CPU transform path stays for the fast path (D7). Proof: emissive loop copy lights a diffuse card — CPU-computed irradiance oracle, synthetic.
- **Gates:** clippy/nextest touched crates; `gpu_proofs_gate.py`.
