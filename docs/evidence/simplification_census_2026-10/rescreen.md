# rescreen sweep

- **Sweep:** rescreen, part of BUG-yn979 (Simplification pass). It judges the 36 non-UI rows of `rescreen-delta.md`: rows the comment- and impl-aware screen (`raw/pub_refs_v2/`) calls DEAD or TEST-ONLY and the original screen did not.
- **Model:** Sonnet 5.5, medium effort
- **Main commit:** 37a9c180a (`raw/main_commit.txt`). `crates/` is identical at d4d34a0c2 (`git diff --stat 37a9c180a HEAD -- crates` is empty).
- **Scope:** manifold-node-engine 16 rows, manifold-playback 9, manifold-nodes-scene 2, manifold-physics 2, manifold-water-gpu-flip 2, manifold-audio 1, manifold-fluids 1, manifold-media 1, manifold-nodes-water 1, manifold-water-gpu-mpm 1. The manifold-ui, manifold-gpu, manifold-app and manifold-ui-paint rows belong to the app-ui sweep.
- **Raw files used:** `rescreen-delta.md`, `raw/pub_refs_v2/manifold-{node-engine,playback,nodes-scene,physics,water-gpu-flip,audio,fluids,media,nodes-water,water-gpu-mpm}.tsv`. Corpus: `/tmp/simplification_census/corpus/projects` (182 projects), a loading check only: a hit would mean a deletion needs a load path, never that the item is used.
- **Method:** per row, the two census commands (`rg -w -F NAME` over the repo, `rg -l -w -F NAME` over the corpus), `git log -S NAME`, then a read of the item, its callers and the code that does the same job in the product. Items that use only each other are one row. `module_check.py` (engine-model scratchpad) followed the rows into their modules.
- **Line counting rule:** the item, its doc comments and attributes, one blank line, and the tests that exist only for it. `~` means the tests or the cascade are estimated, because nothing was built.
- **Denied commands:** none this task.
- **Not covered:** see the end of this file.

Candidates: 14 (A 5, B 5, C 4), covering 24 of the 36 rows; the other 12 are kept after check. Lines removable by grade: A 162, B 373, C 442 (rescreen-002's 175 move into tests, they are not deleted).

Grades: A every search empty, B code searches empty with one named gap, C needs Peter. Every row has its section in `rescreen.proof.md`. Ids of other records used below: engine-runtime-041 (`request_clip_poster`, dead), water-009 (`capture_scene_impulse` wrapper and its getter), water-014 (`visit_hits`, `StepAction`, `pressure_impulse_delta_velocity`), water-019 (the whitewater and sheet oracle feature). They are rows in `engine-runtime.md` and `water.md`.
