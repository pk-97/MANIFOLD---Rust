## Common commands

`REPO` = `/Users/peterkiemann/MANIFOLD - Rust`. Run for every name below (the per-name lines are the output, generated by `hits.py`, which calls the same `rg` and sorts each line it prints):

```
rg --hidden -g '!.git/' -g '!plugins/vendor/' -n -w -F NAME "$REPO"
rg -l -w -F NAME /tmp/simplification_census/corpus/projects
```

How to read a line: `N hit(s)` counts every whole-word match including docs and the definition. `code` lists matches outside the definition that are not in a `//` comment, not an `impl NAME` header and not in docs/beads; `none` means the name has no use. `tests` lists matches inside test code (`*_tests.rs`, `tests/`, `#[cfg(test)]` bodies). `comment-only` counts matches that sit after `//` (the lead's second trap). `docs` names the markdown or bead files that mention it (never a use). `corpus` is the number of the 182 corpus project files that hold the name; 0 everywhere in this file. Paths are shortened: `ui/src/x.rs` is `crates/manifold-ui/src/x.rs`.

The pattern/string checks of section 3.1 were run once for the whole sweep and came back empty for all four crates: `rg -n 'paste!|concat_idents|stringify!' crates/manifold-ui/src crates/manifold-ui-paint/src` (no output); `rg -n 'serialize_with|deserialize_with|default = "' crates/manifold-ui crates/manifold-ui-paint` (no name of a candidate); `.m`, `.swift`, `.h` files: `fd -e m -e mm -e swift -e h . crates/manifold-gpu crates/manifold-app crates/manifold-ui-paint` finds no file in these four crates (the native sources live in `manifold-fluids`, whose files name none of these items, covered by the repo-wide `rg` above); `scripts/ui-flows/*.json` is in the repo-wide search too (asset bucket: 0 for every name).
