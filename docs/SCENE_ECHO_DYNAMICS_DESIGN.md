# Scene echoes and attraction — motion as geometry

<!-- index: Analytic echoes, reversible attraction and bounded recorded-transform history, with explicit seek and simulation boundaries. -->

**Status:** PROPOSED · 2026-09-10 · Codex lead · not implemented.
**Prerequisites:** Foundation F8 and fields W3. Mesh history is not a prerequisite for transform echoes.
**Execution contract:** [DESIGN_DOC_STANDARD](DESIGN_DOC_STANDARD.md) sections 5–6 and 8. Conformance treatment; state-store and buffer lifecycle signatures must be re-derived before E3.

Echoes turn a trajectory into a sculpture. Attraction makes a scene gather, orbit and release. **The first versions evaluate mathematical motion at chosen phases; recorded history is a separate, explicitly stateful feature.** This preserves predictable seek/loop behaviour for the majority of looks.

Shared gates and resource limits: [Validation](SCENE_MODIFIER_VALIDATION_PLAN.md).

## 1. Audit — verified 2026-09-10

Existing array/state vocabulary is in `crates/manifold-renderer/src/node_graph/primitives/array_feedback.rs:32` (Particle-specific), `temporal`/`feedback` primitives and `StateStore` execution. These are lifecycle precedents, not proof of arbitrary transform history. Existing instance rendering shares mesh resources; `scene_object.rs:60` binds instance arrays. The current `InstanceTransform` is position/uniform-scale/Euler plus special marker, not a skeleton pose or deformed mesh snapshot.

Read [EFFECT_CHAIN_LIFECYCLE](EFFECT_CHAIN_LIFECYCLE.md), actual state-store APIs and current GPU retirement rules before E3. Search `clear_state`, `owner_key`, `array_feedback`, `slot_write_generation`, `rt_refit_eligible` across renderer source. No existing generic transform-history primitive was confirmed by this audit.

## 2. Decisions

- **D1:** Analytic echoes repeat an authored motion formula at `phase - sampleOffset`; they do not rerun an arbitrary scene graph, simulation or renderer at historical times.
- **D2:** Each echo is another instance of the same mesh. Mesh buffers/material textures are shared. No extra render pass per echo. Output active count is source count × echo count and must fit prepared capacity and RT budgets.
- **D3:** Source/copy/echo identity is a tuple, stable across frames. Increasing active echo count reveals preallocated entries; no live allocation. Echo 0 denotes the present.
- **D4:** Attraction is initially a reversible positional mapping from reference, not a physical force integrator. The card's Progress can always return home exactly.
- **D5:** Recorded history stores transforms only in v1. It is unavailable for a look whose defining motion is deformation/skinning unless that limitation is explicit in the picker. Do not show frozen duplicate meshes as though their past animation was recorded.
- **D6:** History buffers belong to one stable modifier instance via existing StateStore. Seek, loop discontinuity, source identity/topology change and sample-rate change clear validity; pause holds history. Removal retires buffers through existing GPU lifetime machinery. No shared global ring or new lock.

## 3. Analytic motion and attraction

Represent echo sample offsets with existing range/array math: `offset_j = j * spacingBeats`. Convert `(beat-offset_j)` to each periodic motion's phase through the same beat boundary as the live sample. For a periodic preset, delays wrap in its declared period. Nonperiodic assembly clamps to its authored pre/post states and never advertises seamless wrapping.

The motion subgraph is authored to accept phase samples explicitly. Reuse field/formation sampling and packing operations to produce the repeated transforms. A general "evaluate this entire graph at another time" executor is rejected: it would duplicate state, IO and compilation ownership. Existing arbitrary recorded gestures use E3 instead.

Attraction mapping for source p and attractor c: `p' = c + radialScale * R(axis, angle)*(p-c)`. Scale and angle are functions of Progress, reference distance and stable seed. Progress 0 uses p exactly. Competing centres are a weighted mixture of offsets, with weights generated by the spatial field vocabulary. This produces vortices/streams visually, without claiming Newtonian dynamics or collision response.

First presets: **Orbit Echo** (phase-delayed formation copies), **Spiral Return** (radial contraction plus rotation), **Phase Fan** (rotating object samples spread into a fan). Each uses graph-visible position/rotation sampling. Copy scale can taper older samples within a strictly positive authored range; opacity fading is deferred until the instance/material path supports it. No undocumented `InstanceTransform` padding reuse for alpha.

## 4. Count and identity contract

Capacity is checked as `checked_mul(sourceCapacity, echoCapacity)`. Initial v1 echoCapacity=32, sourceCapacity chosen from the source's admitted maximum. Active echo count is integer [1,32]; entries beyond it remain inactive according to the existing instance contract. Proposed default active echoes=8. Admission uses both buffer bytes and renderer instance/RT capacity, not only the output array length.

`sourceCapacity` is the prepared maximum, never the current live active count. Preserve source slot ordering, including holes: every source slot owns echoCapacity output slots, and an inactive source makes all its echoes inactive. No per-frame compaction or reassignment of source identity. Increasing source active count is admitted only within the prepared maximum.

Per-source motion follows tuple ordering `(sourceKey, echoIndex)` with a deterministic hash for variation. Source transforms compose through the renderer's actual instance/object convention verified in W1. Preserve reflection marker and inactive entries. No Euler-vector arithmetic advertised as general rigid-transform composition; phase sampling computes each complete pose independently.

For recorded history, E3's internal transform pose uses a quaternion and nonuniform scale only if the existing Object Transform source requires it; renderer conversion remains explicit and loss-checked. Do not widen the shared InstanceTransform ABI to store object poses. The v1 recorded-copy mode records only its supported uniform-scale copy representation and rejects incompatible sources.

## 5. Recorded history contract

Proposed node boundary (⚠ VERIFY-AT-IMPL): supported `Array<InstanceTransform>` plus typed current `Beats`, sampling interval in Beats and reset/epoch information → sampled `Array<InstanceTransform>` plus sample validity. It owns a GPU ring with CPU metadata, never reads GPU-written transforms back synchronously. Sample time metadata is CPU-owned; buffer copies occur on the existing command stream.

Sampling is musical-grid-based. For the current beat, record at most one sample for the latest crossed grid point, retaining the actual capture beat in metadata rather than backdating the pose. If more than one point was crossed between rendered frames, mark skipped points invalid rather than invent historical poses. Lookup returns the nearest earlier valid sample within one interval; otherwise that echo is inactive. No silent interpolation across missing history. A post-seek preset builds its history again and displays "History filling" in the control surface. Export begins with declared preroll for recorded-history looks; without adequate history it uses the same inactive-sample rule, not a different fallback.

Capacity is established at prepare time: `historySlots = ceil(historyBeats / intervalBeats) + 1`, checked against 64 MiB per modifier and 256 MiB total per scene. Changing history duration or sample interval is an authoring operation requiring reprepare; changing active echo count/spacing within the admitted window is a parameter gesture. Future interpolation or fixed-step resampling requires a separate contract.

`clear_state` invalidates all history, epoch and last sample beat together. Keep the allocated capacity across ordinary resets where existing StateStore permits, to avoid first-use allocations. Validity is an explicit mask consumed before render/RT instance admission. Two same-preset instances cannot share history by preset ID.

## 7. Phasing

Read back D1–D6, source/instance transform conventions and bounded capacity rules before each phase. Re-derive state APIs before recorded history; the lead pins those exact signatures in the phase brief if upstream code changed.

**E1 — analytic echoes and attraction.** Entry: W3. Deliver only missing phase-sampling/packing operations, OrbitEcho/SpiralReturn JSON and E1/E3 numeric tests. Gate: GPU `scene_modifier_analytic_echo`/`scene_modifier_attraction_return`; check-presets and focused renderer clippy. Demo/gesture: spread phase echoes, then collapse to a single pose after arbitrary seek — L3 target. Forbidden: arbitrary graph reevaluation, hidden integration or alpha-in-padding.

**E2 — renderer qualification.** Entry: E1. Deliver E2/E6 resource and raster/RT tests; bounded counts and explicit picker admission diagnostics. Gate: GPU `scene_modifier_echo_render_paths`, V8 measurement at 8 and 32 echoes. Demo/gesture: count gesture within prepared capacity while camera moves — L3 target. Forbidden: per-echo mesh duplication or per-echo render pass.

**E3 — recorded transform history.** Entry: E2 and fresh StateStore/lifecycle read-back. Deliver ring, validity mask, seek/reset handling, History filling state and preroll policy; E4/E5 tests. Gate: CPU `scene_modifier_history_lifecycle`; GPU `scene_modifier_history_validity`; app flow that records, pauses, seeks, reloads and fills again; touched-crate clippy. Demo: pose trail of a manually modulated rigid source — L3 target. Forbidden: recording vertices/skeletons, fabricating skipped samples, resetting ownership on graph reorder, sharing ring by preset ID.

## 8. Decided — do not reopen

Analytic first; captured history explicitly separate; bounded transform buffers; valid-sample masks; deterministic attraction mapping; instance identity controls state ownership.

## 9. Deferred

Physical attraction, flocking, collisions and chaotic integration belong to the existing [SIMULATIONS_DESIGN](SIMULATIONS_DESIGN.md), with a future modifier bridge. Revival requires a concrete physical look, typed fixed-step Beats/Seconds/Bpm boundary, checkpoint/resimulation policy, deterministic seed/order, bounded substeps and export parity. No v1 modifier silently accumulates velocity. Recorded vertex/skeleton/splat histories, interpolated history, alpha-tapered instances and general arbitrary graph time sampling are also deferred until a scoped resource/representation contract is written.
