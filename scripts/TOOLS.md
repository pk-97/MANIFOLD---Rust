# Repo tools

Generated by `scripts/dev.py --write-index`; `scripts/dev.py --help` prints the same.
`scripts/dev.py <verb> [args]` runs the command in brackets; `<verb> --help` is its usage.


Checks:
  flows                   UI flow suite; bare = flows touched since origin/main, <name> runs one flow, --all runs everything  [scripts/run_ui_flows.py]
  feature-matrix          build every non-default feature so none rots  [scripts/feature_matrix.py]
  rt-noise                RT temporal-stability check on a paused scene (--record to re-baseline)  [scripts/rt_noise_gate.py]
  bridge-probe            presentation tear regression check  [scripts/bridge_probe_gate.py]
  wgsl-check              naga-validate the hand-composed water shader stacks in seconds, no cargo or GPU; names pick stacks  [scripts/wgsl_check.py]
  glb-status              regenerate the glTF conformance status doc  [scripts/gen_glb_conformance_status.py]

Machine:
  gpu-queue               GPU lock: `-- <cmd>` (waits for the MANIFOLD app to quit, else NOT RUN), `status`  [scripts/gpu_queue.py]
  claude-pane             launch a Claude Code session in a new tmux pane without stealing focus  [scripts/claude-pane.sh]
  cache-cleanup           delete incremental build caches untouched for a day, waiting for a gap between compiles (launchd runs it daily at 4:00)  [scripts/manifold-cache-cleanup.sh]
