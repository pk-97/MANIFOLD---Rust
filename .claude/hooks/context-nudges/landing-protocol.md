# Landing reminder

Protocol (`.claude/GIT_TREE_DISCIPLINE.md` section 2): fetch, merge `origin/main` INTO the branch, rerun the gate on the merged tree, then `git merge --no-ff` to main, push. On rejection repeat — never cherry-pick or re-commit content that exists on a live branch. Never delete a branch until `git merge-base --is-ancestor <tip> origin/main` passes. Landing gate = `scripts/landing_gate.py` from the worktree (touched-crate clippy + nextest, deny bans, flow gate, docs/design status, GPU proofs when GPU paths touched). The workspace sweep + `scripts/feature_matrix.py` are NOT landing items — nightly `scripts/trunk_health.py` runs them on main and files beads on red. Commit with a pathspec, never the index. Shipping means the supersession sweep in the same session (design doc status header, `bd close`, `rg` for stale references).
