# Landing reminder

Protocol (`.claude/GIT_TREE_DISCIPLINE.md` section 2): fetch, merge `origin/main` INTO the branch, rerun the gate on the merged tree, then `git merge --no-ff` to main, push. On rejection repeat — never cherry-pick or re-commit content that exists on a live branch. Never delete a branch until `git merge-base --is-ancestor <tip> origin/main` passes. Landing gate = full `cargo clippy --workspace --tests -- -D warnings` + `cargo deny check bans`. Commit with a pathspec, never the index. Shipping means the supersession sweep in the same session (design doc status header, `bd close`, `rg` for stale references).
